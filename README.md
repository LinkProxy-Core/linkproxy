# LinkProxy 官方用户手册

LinkProxy 是一套专为数字货币矿场、算力分流托管与跨境网络中转设计的企业级高性能算力路由系统。

系统提供现代化的 Web 可视化控制台，支持万台矿机高并发稳定连接，具备平滑无损分流、多协议自动识别、加密中转隧道以及完备的运维监控能力。

---

## 软件简介与核心功能

- **多币种深度支持**：支持 BTC、BCH、LTC、ETC、ETHW、ZEC、SC、DASH、CKB、CFX、ALEO、KAS、ALPH，以及新一代算法 PRL、QTC 等 15 个主流币种。
- **单端口全协议通吃**：单个业务端口支持同时接收普通 TCP、SSL/TLS 加密以及专属加密隧道流量，矿机无论开不开 SSL 都能一键接入。
- **平滑无感分流**：在分流或切抽过程中，矿机算力保持全速平稳运行，彻底杜绝算力板跳水、掉板与硬件重启。
- **多钱包比例分流**：支持配置多个钱包按比例精准分账，支持设置 VIP 客户免抽水白名单。
- **极速加密中转隧道**：一键生成单文件免配置中转客户端，跨国中转全流量加密伪装，大幅节省网络带宽。
- **实时监控与精准算力**：提供 10 分钟、1 小时、24 小时真实算力曲线图，实时刷新矿机在线列表与提交明细。

## 推荐组网方案

### 方案 1：局域网单机直连（适合本地矿场直连矿池）
矿机直接连接局域网内的 LinkProxy 网关服务器，LinkProxy 负责与上游矿池建立稳定通信并执行分流：
```
[矿机集群] ─── (TCP / SSL) ───► [LinkProxy 代理服务器] ──────► [上游矿池]
```

### 方案 2：加密中转模式（适合跨国、跨境或网络丢包严重的环境）
在境内矿场部署轻量级“加密中转客户端”，在境外 VPS 部署 LinkProxy 服务端，实现全链路强加密中转与带宽压缩：
```
[境内矿场矿机] ───► [加密中转客户端] ─── (全加密流量隧道) ───► [LinkProxy 服务端] ───► [海外矿池]
```
