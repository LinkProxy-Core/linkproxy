# 04. 安全防护与生产加固指南

矿业中转网关通常暴露在公网，极易遭遇扫描、暴力破解、DDoS 以及恶意嗅探。LinkProxy 内置了多重纵深防御机制。

---

## 1. Web 后台防暴力破解与速率限制

LinkProxy 默认开启了管理员登录防爆破模块：
* **单 IP 错误阈值**：连续 5 次输错密码后，自动锁定该来源 IP 15 分钟。
* **Session 防篡改**：采用加密 JWT 令牌，杜绝 Cookie 伪造。
* **默认凭证修改**：强烈建议首次进入面板后，立即在 **系统设置** 中更改默认的 `admin / admin` 账密。

---

## 2. IP 白名单访问控制（可选高防模式）

若您的管理员具备固定公网 IP 或通过公司 VPN 访问：
1. 进入 **系统设置** -> **安全防护**。
2. 开启 **仅允许白名单 IP 访问 Web 控制台**。
3. 填入受信任的 IP 或 CIDR 网段（如 `123.45.67.89/32`, `192.168.1.0/24`）。
4. 保存后，非白名单 IP 访问 Web 端口将直接被底层 RST 阻断，彻底隐形。

---

## 3. 免配置双向加密中转隧道

针对国内到海外矿池跨国专线不稳、经常被运营商干扰丢包的场景：
* LinkProxy 服务端支持开启加密中转隧道信道。
* 矿场内网只需部署单文件绿色中转客户端，配置服务端的通信密钥，即可建立基于 TLS/AES-GCM 的双向混淆长连接。
* 矿场所有矿机直接连接内网中转客户端，所有流量打包加密穿越公网，完全抗嗅探与抗封锁。

---

## 4. 大客户免抽水白名单 (`FilterWallet`)

针对大算力托管客户或自有特殊矿机，可在抽水配置中设置免抽水白名单：
* 支持以英文逗号分隔填入大客户的子账户或钱包地址。
* 当矿机上线或提交份额时，分流引擎执行毫秒级 O(1) 哈希命中检查；只要匹配白名单，抽水引擎对该矿机永远旁路（100% 直通主矿池），实现精细化合规运营。
