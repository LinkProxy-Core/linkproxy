# 01. 安装部署与快速上手指南

本指南指导您在 3 分钟内完成 LinkProxy 的安装、初始化配置与矿机接入。

---

## 推荐服务器配置

| 规模 | 推荐规格 | 操作系统 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **入门型** | 1核 CPU / 1GB 内存 / 10Mbps 带宽 | Ubuntu 20.04+ / Debian 11+ | 1 ~ 300 台矿机 |
| **标准型** | 2核 CPU / 4GB 内存 / 30Mbps 带宽 | Ubuntu 22.04+ / Rocky 9+ | 300 ~ 2,000 台矿机 |
| **大矿场** | 4核+ CPU / 8GB+ 内存 / 100Mbps 带宽 | Ubuntu 22.04+ / Debian 12+ | 2,000 ~ 10,000+ 台矿机 |

> **提示**：建议优先选择距离目标矿池机房网络延迟低（< 50ms）的云服务器（如香港、新加坡、美国西岸等）。

---

## Linux 一键极速部署

支持 Ubuntu、Debian、CentOS、Rocky Linux、AlmaLinux 等主流 64 位发行版：

```bash
curl -fsSL https://github.com/LinkProxy-Core/linkproxy/releases/latest/download/install.sh | sudo bash
```

安装完成后，终端将显示管理地址与初始凭据：
* **控制台入口**：`http://您的服务器IP:10010/ui/`
* **默认账号**：`admin`
* **默认密码**：`admin`

进入后台后，请第一时间前往 **系统设置** 修改管理员密码。

---

## 控制台快捷命令

安装程序会自动在全局创建 `linkproxy` 快捷命令，在服务器终端任意路径输入即可进入菜单：

```bash
linkproxy
```

支持一键操作：
* `[1]` 启动服务 / `[2]` 停止服务 / `[3]` 重启服务
* `[4]` 查看运行状态与实时日志
* `[5]` 检查与一键无感升级到最新版本
* `[6]` 忘记密码一键重置为默认
* `[7]` 快速开通/放行常用端口防火墙
* `[8]` 执行万台高并发内核参数优化

---

## 添加第一个代理端口

1. 登录 Web 控制台，点击 **端口管理** -> **新建端口**。
2. 填写基本参数：
   * **端口号**：例如 `8888`
   * **币种**：选择 `BTC`
   * **协议模式**：推荐 **`SSLMIX`**（同时支持下游矿机以常规 TCP 或 SSL 加密方式接入，自适应握手）
   * **主矿池地址**：例如 `btc.f2pool.com:1315`
   * **备用矿池**：例如 `btc-asia.f2pool.com:1315`
3. 抽水设置（可选）：
   * 填入抽水百分比（如 `1.0`%）及接收子账户。
4. 点击 **保存并启动**。

---

## 矿机接入配置

在矿机后台（如蚂蚁、神马、阿瓦隆、芯动或挖矿软件内核）的矿池设置中配置：

* **Pool 1**：`stratum+tcp://您的代理服务器IP:8888`
* **Worker**：`您的矿池子账户.矿机编号`（例如 `miner01.001`）
* **Password**：`123`（或任意密码）

保存配置后，约 10~30 秒内矿机即与代理建立握手，并在 Web 控制台展示实时算力曲线。
